Soli's Archive / README Guide

Soli's Archive 프로젝트 정리

이 문서는 Soli's Archive의 전체 구조, PDF OCR 변환 방식, 웹 렌더링 흐름, 앞으로 과목 자료를 추가하는 방법을 한눈에 보기 위한 HTML 설명서입니다.

프로젝트 개요

Soli's Archive는 대학에서 수강한 과목을 학년, 학기, 과목 트리로 정리하고, 각 과목 자료를 웹에서 원본처럼 보면서 검색할 수 있게 만드는 정적 아카이브입니다.

문서 표시 PDF 원본 렌더링 이미지

배포 방식 정적 웹사이트

데이터 구조

작업 흐름

1
HWP 원본 보관

HWP는 원본 보관용입니다. 웹 변환에는 직접 사용하지 않습니다.

2
PDF로 내보내기

한글/한컴에서 HWP를 PDF로 추출해 assets/pdfs/<학기>/<과목명>/에 저장합니다.

3
과목 데이터 연결

data/courses.json에 sourcePdf 또는 sourcePdfs와 html manifest 경로를 등록합니다.

4
OCR 변환 실행

tools/render_html_pages.py가 페이지 이미지와 OCR 텍스트 JSON을 생성합니다.

5
웹에서 표시

웹 앱이 manifest를 읽고 PDF 이미지 위에 투명 OCR 텍스트 레이어를 얹습니다.

PDF OCR 변환

OCR 변환 결과는 과목별로 아래 파일들을 만듭니다. 

assets/html/<학기>/<과목명>/<course-id>/
├─ page-001.webp        원본처럼 보이는 페이지 이미지
├─ page-001.text.json   OCR 텍스트와 위치 좌표
├─ manifest.json        전체 페이지 정보
└─ index.html           단독 HTML 문서

필요 도구

brew install tesseract tesseract-lang
python3 -m pip install -r requirements.txt

전체 변환

python3 tools/render_html_pages.py --lang kor+eng

특정 과목만 변환

python3 tools/render_html_pages.py --course data-structure-summary --lang kor+eng

핵심 파일 역할

index.html 트리형 아카이브 앱 진입점입니다.
course.html 이전 과목 상세 URL을 새 URL로 넘기는 호환용 페이지입니다.
data/courses.json 학년, 학기, 과목, 교수, PDF, HTML manifest 경로를 관리합니다.
js/archive.js 트리 탐색, 과목 상세 렌더링, OCR 문서 검색을 담당합니다.
styles.css 앱 UI, 문서 뷰어, floating 검색바 스타일을 담당합니다.
tools/render_html_pages.py PDF를 페이지 이미지와 OCR 텍스트 레이어로 변환합니다.
