[2] 학습 목표/성과(Learning Objectives/Outcomes)
■ 과목 설명(Course Description)
Based on the previous class "(INTRODUCTION TO COMPUTER SYSTEM",
student will learn the following topics: 

- Data Communication 
- Computer Network 
- Wireless Network
- Network Security

We will learn computer network by top-down approach: Application Layer, Network Layer, Transport Layer, Link Layer.
■ 선수과목 및 공통필수과목(Prerequisites and Co-requisites)
Computer Systems Fundamental (컴퓨터시스템 기초)
■ 학습 목표(Learning Objectives)
- Basic Principle of Computer Network 

- Communication Protocol

- Wired and Wireless Communication

- Network Management and Security

- Networked database and SQL
■ 학습 성과(Learning Outcomes)
- Skills and Techniques  for Network Management  for Communication network 

- Practice on Network Systems and Layers  

- Knowledge for Safety and Security in Computer  Network
