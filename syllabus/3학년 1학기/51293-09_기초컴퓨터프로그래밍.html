[2] 학습 목표/성과(Learning Objectives/Outcomes)
■ 과목 설명(Course Description)
본 과목은 전공 기초 과목으로써, 기본적인 C 언어 문법과 사용을 숙지하는 것을 목표로 합니다.
■ 선수과목 및 공통필수과목(Prerequisites and Co-requisites)
없음
■ 학습 목표(Learning Objectives)
1. 컴퓨터공학에 대한 기본적인 지식 습득
2. C 언어의 기본적인 문법 숙지
3. C 언어를 이용하여 다양한 문제를 해결하는 능력 함양
■ 학습 성과(Learning Outcomes)
앞으로 컴퓨터공학에서 배우게 될 내용에 대한 기본적인 이해와 C 언어를 이용한 프로그래밍 능력을 기를 수 있음
