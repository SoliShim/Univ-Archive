[2] 학습 목표/성과(Learning Objectives/Outcomes)
■ 과목 설명(Course Description)
This course aims to learn about the programming skills needed for the various fields of business.
Specifically, the lecture will cover the basic concepts and grammer of Python.
We will also cover some machine learning algorithms for the business data analytics using the external libraries of Python.
■ 선수과목 및 공통필수과목(Prerequisites and Co-requisites)
■ 학습 목표(Learning Objectives)
- Learn about the Python
- Understand how to write and read Python code
- Complete own data analytics project using Python
■ 학습 성과(Learning Outcomes)
This course aims to make students write own Python code for business data analytics.
