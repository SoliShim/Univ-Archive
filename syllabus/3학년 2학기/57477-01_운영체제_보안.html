■ 과목 설명(Course Description)
Operating Systems (OS) manage computer resources (memory, CPU, storage). OS connect SW and HW in computers  
OS communicate components inside computers and components outside computers. 
 
This course provide the understanding of OS and  security of  OS (memory protection, disk protection, access control, user authentication). Also, student 
will  study and practice cloud systems (e.g., amazon web service (AWS) elastic compute cloud (EC2)).

There is special lecture from OS-related company (e.g., LG electronics vehicle solution division).

We recommend this course to third year students who took 'COMPUTER NETWORK' or equivalent class.
■ 선수과목 및 공통필수과목(Prerequisites and Co-requisites)
Linux experience and programming skilll
■ 학습 목표(Learning Objectives)
- OS BASIC

- CPU Scheduling, Concurrency, Memory and file management

- OS security (memory protection, disk protection, access control, user authentication)  

- Cloud Systems (Virtualization,  Docker)
■ 학습 성과(Learning Outcomes)
- OS theory (CPU Scheduling, Concurrency, Memory and file) and security (memory protection, disk protection, access control, user authentication)  

- Coding Practice or Linux Priace for modern operating systems including (GIT and scheduling practice)

- Mini-project on Xv6, a simple Unix-like teaching operating system
